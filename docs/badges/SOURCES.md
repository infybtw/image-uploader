# README badges

These self-contained SVGs are stored locally so viewing the README does not
request badge images from an external badge service. Brand icons are embedded
inside the SVG files; no external fonts, scripts, or images are required.

Firefox, JavaScript, Tampermonkey, and GitHub badge presets come from
[Ileriayo/markdown-badges](https://github.com/Ileriayo/markdown-badges/tree/b7c1c47f33b4bd5c36fe6971ddc7f1ac1dbb1eca).
The upstream catalog uses Shields.io to render its badges. These files are saved
SVG renders of those presets, with action-oriented captions where appropriate.
Violentmonkey is not in that catalog; its text-only badge uses the same style.

| File                  | Preset / adaptation                                       |
| --------------------- | --------------------------------------------------------- |
| `mozilla-addons.svg`  | Firefox preset; caption changed to Mozilla Add-ons.       |
| `userscript.svg`      | JavaScript preset; caption changed to Install userscript. |
| `tampermonkey.svg`    | Tampermonkey preset.                                      |
| `violentmonkey.svg`   | Custom purple, text-only badge in the same style.         |
| `github-releases.svg` | GitHub preset; caption changed to GitHub Releases.        |
